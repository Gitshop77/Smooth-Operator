Local Vision Assistant (WebGPU)

Runs a vision model entirely in your browser via WebGPU — zero API cost, fully private. It uses ~2.5 GB of memory and is recommended for text-only LLMs (DeepSeek, Llama, Qwen, etc.); it adds visual element detection the DOM can’t see (Canvas, WebGL, visual layout).

About

Open-source agentic browser control.

Open Cowork v0.3.1 — bring your own LLM key. Your task data is sent only to the provider you choose.

Features

  • 32 actions (click, input, select, scroll, navigate, evaluate, …)
  • 16 LLM providers (Ollama, OpenCode, OpenAI, Anthropic, Gemini, …)
  • Vision support (dual-channel DOM + screenshot)
  • Streaming (SSE — real-time reasoning display)
  • Loop detection + context compaction
  • Prompt-injection defense
  • Run history + transcript replay
  • Scheduled tasks (chrome.alarms)
  • Secret management (%var% substitution)
  • Cost tracking + budget caps
  • MV3 lifecycle resilience
