Local Vision Assistant (WebGPU)

Runs a vision model entirely in your browser via WebGPU — zero API cost, fully private. It uses ~2.5 GB of memory and is recommended for text-only LLMs (DeepSeek, Llama, Qwen, etc.); it adds visual element detection the DOM can’t see (Canvas, WebGL, visual layout).

About

Open Cowork v — bring your own LLM key. Your task data is sent only to the provider you choose.

Features

  • 32 actions (click, input, select, scroll, navigate, evaluate, …)
  • 16+ LLM providers (Ollama, OpenCode, OpenAI, Anthropic, Gemini, …)
  • Vision support (dual-channel DOM + screenshot)
  • Streaming (SSE — real-time reasoning display)
  • Loop detection + context compaction
  • Prompt-injection defense
  • Run history + transcript replay
  • Scheduled tasks (chrome.alarms)
  • Secret management (%var% substitution)
  • Cost tracking + budget caps
  • MV3 lifecycle resilience

Permissions & privacy

This extension requests powerful permissions so it can act on whatever page you point it at:

  • debugger — can attach to any open tab (including incognito), read its DOM, and synthesize input as if you were clicking and typing.
  • scripting — injects scripts to drive page automation.
  • tabs + universal host access — read access to any origin the assistant operates on.

For sensitive or authenticated sites, prefer a restricted host-permission scope rather than granting universal access.

A supply-chain compromise (malicious update, compromised dependency) would gain unrestricted access to all user data across all sites. This is inherent to the browser-automation model. See Security and trust (opens in new tab) for mitigations.
