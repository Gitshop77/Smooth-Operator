Agent behavior

Local vision assistant (WebGPU)

Runs a 2.1 GB vision model (LocateAnything-3B) entirely in your browser via WebGPU — zero API cost, fully private. Highly recommended for text-only LLMs (DeepSeek, Llama, Qwen, etc.) — it adds visual element detection the DOM can't see (Canvas, WebGL, visual layout). Cheaper than using vision in a vision model — local vision runs on your machine with no API token cost, while vision models charge per screenshot. Using GPT-4o, Claude, Gemini, or other vision models? You can still use local vision by disabling screenshots below — your model will work as text-only + local vision, saving API costs.

Not loaded

Secrets

Store credentials locally. Use %name% in your prompts — the LLM only sees the placeholder, the real value is substituted at execution time and never sent to the LLM.

Scheduled tasks

Schedule recurring agent runs. Uses chrome.alarms (MV3-compliant).

Note: Scheduled tasks only run while Chrome is open. The extension will prevent your computer from sleeping while a scheduled task is pending (via the power permission) — but if Chrome is closed or the computer is shut down, the alarm will not fire.

Custom tools

Define custom JavaScript tools the agent can invoke. Each tool has a name, description, and a function body that runs with the page's window/document in scope. The agent invokes them via the existing evaluate action — no need to modify the action schema.

Run history

Past agent runs. Click to view the full transcript.

Custom domain skills

Define site-specific instruction packs. When the agent visits a matching domain, the skill's instructions are loaded on-demand via the load_skill action.

Custom system prompts

Override the default Navigator and Planner system prompts. Leave empty to use the built-in defaults.

Notifications

Get notified when a run completes, even if you've switched to another tab.

About Open Cowork

Open Cowork v0.3.1 — open-source agentic browser control.

Planner + Navigator multi-agent architecture, built on a multi-agent agentic loop. Bring your own LLM key. Your task data is sent only to the LLM provider you choose — no intermediate server. For fully local operation, use the Ollama provider.

Features

  • 32 actions (click, input, select, scroll, navigate, evaluate, …)
  • 14 LLM providers (Ollama, OpenCode, OpenAI, Anthropic, Gemini, …)
  • Vision support (dual-channel DOM + screenshot)
  • Streaming (SSE — real-time reasoning display)
  • Loop detection + context compaction
  • Prompt-injection defense
  • Run history + transcript replay
  • Scheduled tasks (chrome.alarms)
  • Secret management (%var% substitution)
  • Cost tracking + budget caps
  • MV3 lifecycle resilience
